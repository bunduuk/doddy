Edge Add-ons support and automatic update checks.

## What's new

- **Doddy is on the Microsoft Edge Add-ons store.** Install the extension from the store in Edge, then use this version of the app. The app now recognises both the store version and the one you load from a folder, so Chrome, Edge, Brave, Vivaldi and Arc all keep working.
- **Automatic update checks:** Doddy now looks for new versions every few hours while it is open (it used to check only at launch), and tells you once per new version. Switch it off in Setup → Updates → *Check automatically*.
- **Clearer update message** that says what to do with the download.

## Install

Open **Doddy-0.2.3.dmg**, drag **Doddy** into **Applications**, then reload the extension (unzip **Doddy-extension-0.2.3.zip**, or press reload on `chrome://extensions`). If you use the Edge store version, you don't need the zip. Not notarised: if macOS blocks it, run `xattr -dr com.apple.quarantine /Applications/Doddy.app`.
